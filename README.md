# ApplyFlow 网申自动填写

秋招网申简历一键填充的浏览器插件(Chrome/Edge MV3)。

**核心理念:只填不交**——插件负责把结构化档案填进任意网申表单,核对与提交始终由你本人完成,不触碰验证码、不绕过反爬、不模拟提交。

## 功能

- **结构化档案**:基本信息/教育/实习/项目/获奖/技能/家庭(央国企标配)/求职意向/自我评价/开放题答案库/附件(证件照、简历 PDF 等)
- **简历导入**:上传 PDF/DOCX 简历自动解析成档案草稿(已适配"日期单独成行/公司名下一行/个人优势"等真实版式),人工校对后保存
- **通用填表引擎**:纯规则同义词词典匹配字段,支持文本/原生 select/自定义下拉(antd/element/ivu 等组件库)/radio/checkbox/日期/文件上传(DataTransfer)
- **重复区块**:识别教育经历/实习经历/家庭成员等区块,档案条目多于页面行数时自动点「添加」增行逐行填入(React 重渲染竞态已处理:逐行创建、等待渲染、稳定 fieldId)
- **手动映射记忆**:遇到词典覆盖不了的字段,在侧边栏下拉手动指定一次,按「页面结构签名」记忆,同结构页面下次自动生效(纯规则方案的"学习"机制)
- **开放题答案库**:问题关键词命中即自动填入预存答案(职业规划/为什么选择我们等)
- **系统适配**:Moka(mokahr.com)/北森(italent)检测识别,其余站点走通用兜底

## 安装(开发者模式)

```bash
npm install
npm run build
```

1. Chrome 打开 `chrome://extensions`,开启右上角「开发者模式」
2. 「加载已解压的扩展程序」选择本项目 `dist/` 目录
3. (可选)开发时 `npm run dev`,CRXJS 会热更新,重载扩展即可

## 使用

1. **建档案**:右键插件图标 → 选项页(或在侧边栏点「管理档案」)→ 「导入简历(PDF/DOCX)」→ 校对各区块 → 保存。建议把附件(简历 PDF/成绩单)也传进「附件」页
2. **填表**:打开任意网申页 → 点插件图标打开侧边栏 → 「连接页面」→「扫描表单」
3. 检查字段映射列表(绿色值预览=将填入的内容,未映射的用下拉手动指定)→「一键填充」
4. **人工核对页面,自己点提交**

多页表单(北森类):每页「扫描→填充」,翻页后重复。

## 架构

```
src/
├── core/          # 纯逻辑(可单测):档案 schema、同义词词典、字段匹配、简历解析、日期/文件工具
├── scanner/       # DOM 扫描:控件/标签/选项提取、下拉容器识别、radio 组、重复区块检测
├── filler/        # 确定性填写:原生 setter + input/change 事件(防 React 覆写)、选项文本匹配、下拉轮询、增行编排
├── adapters/      # 系统适配器注册表(moka/beisen,新增系统在此登记)
├── content/       # content script:SCAN/FILL 消息处理
├── panel/         # 侧边栏:映射预览/手动映射/覆盖报告
├── options/       # 档案编辑器
└── background/    # service worker
```

### 匹配优先级

手动映射记忆(override) → 同义词规则(精确 > 标签含词 > 词含标签,歧义放弃交人工) → 开放题答案库 → 不填

### 稳定 fieldId

字段 id 由「区块+行号+标签+控件类型」内容生成,与扫描顺序无关;重复区块增行后重新扫描,已有映射不会错位。页面结构签名(标签+类型指纹)作为手动映射记忆的 key,模板改版但字段不变时记忆仍有效。

## 如何扩充

- **新字段表述**:`src/core/synonyms.ts` 加同义词(term 越长优先级越高)
- **新系统适配**:新建 `src/adapters/xxx.ts` 实现 `Adapter` 接口,登记到 `adapters/index.ts`;真机校准选择器时优先改 adapter,通用逻辑勿动
- **真实页面回归测试**:把网申页 HTML 存片段进 `tests/`,按 `tests/scanner.test.ts` 的方式建 fixture

## 已知限制(真机校准清单)

- Moka/北森的自定义下拉/年月选择器的**具体 class 名需真机核对**(通用引擎覆盖 antd/element 等常见组件库,portal 渲染的选项会全文档搜索);实测失败时把下拉选项的 DOM 片段补进 `filler/fill.ts` 的 `OPTION_SELECTORS` 或对应 adapter
- 文件上传走 DataTransfer,少数站点校验真实文件选择器事件,标记为 best-effort
- 跨域 iframe 内的表单:content script 已 `all_frames: true`,但侧边栏「扫描」只连当前主框架排查到的第一个响应帧,极端布局需在 iframe 内右键单独处理
- 富文本编辑器(简历描述富文本)暂不自动填写
- 多档案版本(不同岗位方向)暂未实现,可用「导出/导入 JSON」切换
